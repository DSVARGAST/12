# DOCE Frontend

Este repositorio quedo preparado para correr solo el frontend.

## Que incluye

- Dashboard visual en React
- Datos demo locales para publicaciones, cuentas y metricas
- Inicio de sesion visual en modo demo

## Como ejecutarlo

```bash
npm install
npm start
```

La app abre en `http://localhost:3000`.

## Notas

- Ya no depende de backend ni de base de datos para funcionar.
- Cuando construyas tu nueva API, puedes reemplazar los datos de [demoData.js](c:\Users\USUARIO\Desktop\12\12\src\data\demoData.js).
